# Kartel

A Beach Buggy Racing–style kart racer for the Solana Seeker, built for the CLOCK IN hackathon (Sep 8 – Oct 8, 2026).
Unofficial parody. Not affiliated with or endorsed by any person or company depicted.

## Build from source

- Unity **6000.3.24f1** (Hub: Android Build Support + OpenJDK + Android SDK & NDK Tools). Open the project; it targets Android, IL2CPP, ARM64, GameActivity.
- One third-party package is **not** in this repo (its licence forbids redistribution): Cartoon FX Remaster FREE → `Assets/JMO Assets/` (Asset Store). Everything else, including the MIT kart physics, is here. Online rooms need no SDK: they run on a Cloudflare Durable Object inside `worker/`.
- Headless, reproducible steps (all also in the **Build** menu):
  - `Unity -batchmode -projectPath . -executeMethod ProjectSetup.Apply -quit` — every Player/URP/Quality setting
  - `… -executeMethod ContentSetup.Build -quit` — materials, driver and kart prefabs
  - `… -executeMethod SceneSetup.BuildGate -quit` — the gate scene
  - `… -buildTarget Android -executeMethod AndroidBuild.Release -quit` — release-signed APK (keystore + passwords via `ANDROID_KEYSTORE*` env vars)
- `BuildSettingsGuard` fails any Android build whose settings drifted from the plan.
- Backend: `worker/` (Cloudflare Worker + D1 + one Durable Object class for online rooms). `npm i && npm run db:remote && npx wrangler deploy`. Secrets: `SESSION_HMAC_KEY`, `HELIUS_URL` (a Solana RPC that allows `getSignaturesForAddress`), `TREASURY_SECRET` (the payout hot wallet; payouts stay pending without it). `PAID_ROOMS="0"` in `wrangler.toml` turns every room free; `PAID_BLOCK` lists the jurisdictions refused paid entry. Local check: `npx wrangler dev --port 8787` (with `MOCK_CHAIN=1` in `.dev.vars`) then `node scripts/smoke-room.mjs`.
